# Video intake review

- Match the current bound video project and the user's requested scope.
- Show the actual source directory label and candidate filenames from the scan.
- Explain exclusions from the actual scan result; do not promise excluded files
  will become available after import.
- Propose a manageable selection using returned entry identities. Ask for
  clarification when the user's selection rule cannot be established from the
  available metadata.
- Preserve the normal confirmation for the exact selection. Scanning, importing
  and viewing the imported videos are separate actions.
- If a source changes, reselect only after the failed operation is known not to
  have committed. An uncertain import requires status readback first.
- Base completion on durable receipts, not a prepared list or a generated plan.
- Do not infer scenes, people, dialogue or visual quality from filenames alone.
