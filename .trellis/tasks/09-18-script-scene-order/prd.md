# 剧本场次与排序工作流

## Goal

减少剧本到场次、场次到镜头的重复录入，并允许用户安全调整创作顺序。

## Requirements

- **S1** 用户可选中剧本文本创建场次，场次记录文本范围并预填内容。
- **S2** 剧本变化导致范围失效时保留场次内容并移除错误关联。
- **S3** 支持连载集、场次、镜头排序，刷新后顺序一致。
- **S4** 支持复制场次和镜头；复制场次可选择是否复制其镜头。
- **S5** 删除、排序、复制后的批量变化可短时撤销。
- **S6** 排序和复制由 repo 事务保证 owner、episode 和 order 不变量。

## Out of Scope

- 自动拆场和 AI 场次识别
- 多选文本建立多个场次

## Acceptance Criteria

- [ ] AC1 选中一段剧本可建立预填内容的场次（S1）
- [ ] AC2 修改剧本使范围失效后，场次内容仍在且不错误高亮（S2）
- [ ] AC3 集、场次、镜头均可重排且刷新后稳定（S3, S6）
- [ ] AC4 复制场次/镜头生成独立 ID 和连续顺序（S4, S6）
- [ ] AC5 最近一次删除或排序可恢复（S5）
