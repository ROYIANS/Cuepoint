# 定向代码复核

日期：2026-09-21

## 范围与结论

复核 `ProjectGalleryPage.tsx`、`projectKinds.tsx` 对本任务 PRD 的符合程度，并核对 Shell 与既有聊天、任务、素材路由的连接。修复以下问题后，未发现本次修改中的阻塞性问题。此记录是代码审查，不替代主会话的浏览器验证与完整质量检查。

## 本次审查发现并修复

1. **项目加载被误展示为空列表。** 新增的“从第一部作品开始”状态建立在 `useLiveQuery(...) ?? []` 上，查询尚未返回时也会显示首次创建提示。保留项目查询的 `undefined`，加载时显示 `role="status"` 的“加载项目中…”，查询完成后才判断真正的空列表。筛选仍复用现有函数。
2. **新建项目弹窗缺少描述关联。** 为扩展后的类型选择弹窗增加 `DialogDescription`，说明视频已开放、其他类型陆续加入，并由 Radix 正确关联可访问描述。

3. **任务与聊天双重 aria-current。** 主会话浏览器发现 TanStack Link 默认前缀激活会在 `/agent/tasks` 为 `/agent` 链接强制注入 `aria-current`，覆盖显式值。查阅本地 Link 实现确认后，对桌面和移动菜单均设置 `activeOptions={{ exact: true }}`；相关详情路径仍由既有自定义判断设置 `aria-current` 与样式。

只修改以上局部内容；未重排整份文件，也未修改旧的重命名、备份和删除实现。

## 核对结果

- 五种类型完整：视频、图片、文案、播客、音乐；列表筛选和创建面板复用同一个展示目录。
- 创建可用性同时由按钮 disabled 和 `handleCreate` 守卫控制，未开放类型不会落入视频仓库创建分支。
- 同步 `creatingRef` 在首个 await 前置位，阻挡连续点击产生重复记录；submitting 禁用类型、名称、形式、画幅及操作按钮，弹窗关闭回调也有同步守卫。
- 创建名称去除首尾空格，空白名称禁止提交；失败保留填写内容并显示现有 toast 错误，finally 解除提交锁。
- 旧项目仍从原表读取，按视频展示，不引入新的持久化类型或 ZIP/schema 迁移。原有打开、搜索、排序、备份、重命名、删除路径保持。
- 视频“单片/连载”明确改称“视频形式”，不与创作类型混淆；无项目类型切换或跨类型复制入口。
- 新建弹窗采用 3/5 列响应布局、85dvh 上限和内部滚动。类型按钮有 aria-pressed 与 focus-visible，项目名称关联 label。
- 新入口无假数据、假计数或无效关注按钮；IP 与媒体统一管理均明确为即将推出。
- `/` 保留聊天重定向；`/agent/tasks` 接既有 TaskBoard，并与聊天菜单高亮互斥。
- 既有角色/场景/道具/风格列表和详情地址保留，Shell 提供素材库返回路径；项目内资产编辑路由未改变。
