## Native range playback and unavailable bytes

- Import a genuine playable synthetic video larger than32MiB and longer than several256KiB chunks. Record source bytes/hash and duration. Preview must use opaque native URL, preserve ordinary controls and load metadata.
- Start playback, verify advancing time beyond the first chunk, seek to a later position, verify continued playback and end-of-file behavior. Observe real WK range requests or bounded response evidence when possible; primitive unit tests alone are not playback proof.
- Preview URL must reveal no physical root/path. Release/reopen revokes the old capability. A closed/missing/corrupt underlying file cannot return successful bytes from a stale cache.
- The application-owned loopback endpoint binds only127.0.0.1 on a random port and receives an opaque capability URL. It is local media delivery, not a sync server. Confirm the actual WebKit media requests work under the narrow media CSP and supplied-origin checks; raw HTTP tests cannot establish this. Full GET must reach the complete file, ranges must support later seek, and HEAD must contain full metadata without a body.
- Mount a grid with more than64 idle preview capabilities, open a detail preview and release/remount it. Capability metadata must not hold a descriptor per idle card. Active reader limits, cancellation and timeout must release capacity; a later item must not stay loading because earlier cards remain mounted.
- Each capability's initial verified hash is distinct from later request identity checks. Record that repeated seeks do not rescan the full file on every request; root/file replacement must invalidate the capability even when the byte length matches.
- Export selected managed bytes through the existing save flow; verify actual saved byte length/hash. Canceled Save does not delete the internal row or regenerate content.
- Missing/corrupt internal synthetic files preserve their logical records, slot/timing/history references and show truthful unavailable feedback. Restore only the known fixture copy if needed; do not delete unknown files.
