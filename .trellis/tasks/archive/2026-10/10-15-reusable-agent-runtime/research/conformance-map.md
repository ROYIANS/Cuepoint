# Sixteen semantic contracts and actual witnesses

The extraction inventory defines these sixteen contracts. Production Studio tests run through the extracted core/provider path; independent tests are `examples/agent-todo/src/conformance.test.ts`, compiled and executed outside the workspace by the packed gate. No entry below substitutes a memory simulation for SQLite/process acceptance. Final command and hash receipts belong in `verification.md`.

The core direct tests complement these host witnesses: atomic missing-completion refuses success, committed-after-throw wins, unreadable outcome remains unknown, non-atomic rejected completion emits no confirmed success, stale checkpoint emits no confirmation, primitive preview zero remains valid, settled calls skip fresh point reads, and the real context/loading helpers have their own bounded conformance tests. Root and native suite receipts establish execution of existing product-specific scope, memory, references, generation and finishing assertions; those remain distinct from this noncreative example.
