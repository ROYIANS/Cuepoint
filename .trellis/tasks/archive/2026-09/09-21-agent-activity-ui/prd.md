# Agent 执行过程与待办提醒

用户明确要求开始下一个交互修改任务，按四张参考截图实现。

## 用户行为与验收
- 执行中顶部实时显示本轮用时；按时间顺序呈现过程文字、思考和工具/技能组。
- 连续工具调用合并到弱化的独立折叠组，始终可手动展开/收起，包括失败、待批准状态。
- 执行完成后过程默认全部折叠，只保留最终答复；可展开查看历史，旧会话兼容。
- 输入框上方紧凑持续提示需要用户处理的工具审批、批次确认/暂停/未知结果和可恢复执行，提供直达操作界面的按钮。模型完成不能掩盖待确认批次。
- 保留原审批、付费确认、未知结果禁止重发、草稿保护及任务生命周期行为。
- 桌面与390px手机布局不溢出，键盘可展开和跳转；计时不能每秒重绘全部历史消息。

## 用户追加：对话快速定位
- 聊天左侧轮次刻度导航，当前阅读轮次高亮。悬停/聚焦预览该轮提问与答复摘要，点击跳到该轮。
- 长对话不挤占正文；键盘可用，390px可触达且无横向溢出。手动跳转暂停自动跟随。

## 用户追加：工具失败可解释性
截图 business_read_text limit=24000 超过12000上限，原错误掩盖字段详情，解析失败默认highRisk=true误导。需向用户和模型提供字段/约束/修正建议，区别未执行与执行失败/结果未知；完成后折叠标题仍提示含失败，不能暗示所有工具成功。不自动重放写入/网络/付费请求。

## 定位栏视觉补充
达到5轮才显示，默认极短细线，最多同时露出10条，其余内部滚动。hover中心与邻近刻度按距离逐级伸长形成波浪；键盘聚焦同等预览、尊重减少动画。

用户最终微调：footer背景遮罩向上延伸136px，背景模糊22px，前景控件不模糊；轮次刻度左端统一、默认含active均为6px，active仅变色，只有鼠标hover改变长度。桌面间距12px/至多120px高，手机20px/至多200px高。
