# AI 的 IP / 素材能力与工具按需加载：交付报告

日期：2026-09-21。范围由用户“可以，我们开始吧”确认。代码与验证已完成；用户随后明确要求提交并归档，本任务按该授权完成本地提交及归档，不推送远端。

## 已落地的能力

### 聊天管理 IP

新增 6 个明确工具：搜索、分页读取档案、创建、修改、归档/恢复、关联/解除项目 IP。创建前展示名称、定位、受众、主题、表达、视觉与声音字段，用户在现有确认卡批准后才实际落库。共享修改展示影响数量；审批后目标版本或影响范围变化，会拒绝旧预览而不覆盖新数据。

项目聊天自动附带所属 IP 的有界摘要和版本，完整字段按需读取。修改、归档、解除关联在下一次稳定请求边界刷新事实；IP 内容作为创作资料，不构成授权。其他项目/IP 的完整内容不会因为检索名称目录而开放。

### 聊天整理、读取和采用素材

新增 10 个工具，覆盖：搜索原始资料或版本素材，查看名称/标签/备注/类型/归属/版本/用途，整理元信息，保存独立快照，显式复制，项目采用固定版本，加入新版副本，归档恢复，移除未引用的项目副本。

通用、IP 专属、项目专属的归属与页面共用规则。修改素材库不会自动替换已有项目副本，更不会自动替换镜头、封面或生成槽位。IP 正式素材提升、共享元信息变更及归档通过现有确认机制处理。移除前先保存项目待写入编辑，实际引用存在时拒绝移除。

图片按明确版本向当前视觉模型传真实像素。文档通过已有解析器读取 TXT、Markdown、文字型 PDF、DOCX，每次最多 3 段、12,000 字，保留页/段/行与来源版本，明确未读范围。素材音频、视频本轮只支持元信息，不宣称听取、观看、转写或编辑。

图片/文字读取记录保留身份和 SHA-256，后续请求校验同一执行、文件版本、当前归属及归档状态。二进制不会写入普通工具 JSON；像素只在 HTTP 发送前解析。历史任务与总结保留来源身份及范围，不重放素材正文或像素。

### 工具按需加载

权限上限与每轮工具清单独立保存。新执行默认提供基础工具和简短能力目录，模型调用 `load_tool_groups`，下一轮才收到所选能力的定义和说明。最多同时选择两组，工具集合上限 36；待确认/待执行调用保留依赖。

禁用能力不会出现在目录；加载不扩权；同一响应里加载尚未提供的工具并直接调用会被拦截。Chat Completions、Responses、预算、上下文压缩、审批和恢复使用同一实际工具集合。旧执行保持原始快照，纯对话仍无工具。

上下文明细分别显示：当前工具数量、可按需加载能力组、已加载组、工具定义估算、技能/目录估算、工具结果占用。供应商返回的实际输入和缓存命中 tokens 另行保留；未返回不编造零值。升级设置保留已有能力关闭选择，全关闭也保持关闭。

## 复核修正与边界

复核中修正了：新配置迁移时保留关闭选项；JSON 序列化后可选字段影响来源校验；旧账本测试缺少“工具已经被提供”前提；移除副本前待写入引用保护；归档素材只显示元信息；素材图片在工具执行阶段校验视觉能力、累计图片数和可解码格式；解除 IP 关联后仍允许按项目副本权限清理闲置文件。

本轮没有实现音乐编曲、播客制作、视频自动剪辑、周边专用编辑器、图片编辑器、永久删除工具或任意文件/URL读取。已有图片/视频生成仍遵循原有确认流程。

项目解除 IP 关联后，仍可明确清理本项目自己已采用且无引用的旧副本；清理只使用本地副本与使用记录，不开放原 IP 素材的读取或新版采用权限。工具历史和当前执行失败保留，不会伪称失败后已经读取/修改成功。
