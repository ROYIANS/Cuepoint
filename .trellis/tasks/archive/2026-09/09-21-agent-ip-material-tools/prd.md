# AI IP / 素材能力与工具按需加载

## 目标
用户希望在现有聊天入口中让 AI 真正建立 IP、整理和复用素材，同时减少每轮传给模型的工具占用。用户原话：现在 AI 是否可以帮我创立 IP、处理素材，扩展一下；工具太多是否不可避免。

## 已确认现状
- IP 与版本素材库已落地（7c805d4），但 Agent 注册表未连接 ipProfiles/materials repositories；当前只能文字建议，不能创建持久 IP 或操作新库。
- tools.ts 注册 57 个工具；默认技能去重 50 个，未绑定项目过滤到 44 个（均不包含额外任务记账工具）。默认技能说明仍整体拼接。
- runChat.ts 每次模型请求把 enabledToolNames 全部转换为 schema，预算也按全量计算；没有渐进发现/加载。
- 默认工具 schema 35,308 字符，项目估算器估计 11,865 tokens，技能说明另约 1,951 tokens。未绑定工具 schema 32,286 字符，估计 10,661 tokens。是本地启发式估算，不是供应商计费。
- 纯对话模式已不带工具；已有权限模式、确认卡、冻结run、原子执行账本、双协议和项目范围合同必须保留。

## 已确认要求
R1 IP：聊天搜索/读取、创建、修改、归档恢复、为项目关联或解除 IP。创建 IP 用可读确认卡先呈现名称/定位等字段；修改展示改动和影响，沿用权限模式。不能猜测同名对象，不能自动跨 IP 批量修改。
R2 创作上下文：绑定项目只带所属 IP 的有界摘要和版本；未绑定聊天按用户明确对象搜索。完整偏好按需读取，撤销关联/归档后刷新事实，其他 IP 不自动进入请求。内容只是创作数据，不提升为系统授权。
R3 素材：搜索/读取类型、归属、版本、用途；修改名称/标签/备注；将已存在的项目/工作室媒体或设定保存为版本素材，明确确认全局/IP/项目归属；显式复制、项目采用、新版副本、归档恢复和未使用副本移除。正式 IP 素材提升需确认，不能将任意生成候选自行视为正式形象。
R4 理解素材：新库图片可按明确版本传真实像素给当前视觉模型；TXT/Markdown/PDF/DOCX按需提取和分页读取；视频音频本轮只读元信息与已有文字资料，不能声称已听/看内容。文件来自现有库和上传入口，不开放任意本机文件读取或任意远程下载。
R5 工具负载：常驻少量基础工具和短能力目录，按需发现并加载业务工具及相应技能说明。用户禁用的能力始终不可发现/执行；发现不会提升权限。本轮已加载集合有界且持久，跨能力长任务可显式切换组，待审批或未完成调用不可被卸载。历史执行可恢复。
R6 通用兼容：先用应用层普通function实现按需加载，适配现有Chat Completions/Responses连接；不依赖所有供应商支持原生tool_search。严格参数schema和按操作的风险/确认保留。
R7 可观察：实际可调用数量/可发现数量、schema与技能估算、工具结果占用分别显示；供应商真实usage与缓存指标有返回时另记，不混淆估算与账单。长结果先摘要+ID+分页，避免整库Blob/Base64进入普通工具结果。

## 验收
- “建立 INFP 美食博主 IP”→可读确认→真实创建一次→IP页面可见；取消不落库；冲突不覆盖。
- 按该IP给出内容建议能引用正确已读档案；项目关联变更不残留旧IP事实。
- 搜索素材→按版本看图/读文档→整理标签→提升/采用/归档能在页面观察结果；旧项目版本不自动改变；引用保护与来源快照完整。
- 默认首轮不再发送全量44–50个工具；以同一估算口径验证首轮工具+技能占用至少降低60%，并报告发现轮次及端到端开销，非保证账单降低60%。
- 智能模式单领域任务只加载相关工具；混合任务能转到其他领域；未加载/已禁用工具拒绝执行，伪造发现结果不能授权。
- Chat/Responses、停止/重载/审批续跑、旧run兼容、待审批不重放以及当前业务回归均通过。
- UI复用现成控件；测试不调用真实付费生成服务。

## 不包含
音乐编曲、播客制作、视频自动剪辑、独立图片编辑器、IP周边制作；任意本机/远程文件访问；AI永久删除素材；全素材库备份；新向量服务/额外付费路由模型。保留现有图片视频生成流程的确认要求。
