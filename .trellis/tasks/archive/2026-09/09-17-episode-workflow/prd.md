# 分集工作流与分镜表

## Goal

进一部戏先看见第几集。能新建第 1 集、第 2 集、第 3 集；点进某一集才写本集故事、做本集分镜。世界留在系列层。分镜表按 AI 做剧排成首帧 / 尾帧 / 成片，不再按现场拍摄当默认。

## User value

作者按「一部戏 → 第几集 → 这一集的故事和镜头」工作，而不是打开项目就掉进一张整部戏共用的分镜表。

## Background

当前没有 `Episode`。`Project.story` 存一句话、剧本、场次；镜头只挂 `projectId`。进项目落在故事页，顶栏是故事 / 世界 / 分镜 / 制作。分镜固定列是顺序、镜号、画面、参考；可开关列里有一批摄像机字段。故事和场次全是文本框。父任务已把「集列表、镜头挂到集上」标为延期，并把短片写成隐形一集——本次改为集必须可见。

## Requirements

- **E1** 进入项目第一屏是集列表。可创建下一集（第 1、2、3…）。新建项目自动有第 1 集。不能删掉最后一集。
- **E2** 点进一集后，顶栏变成该集的 **故事 / 分镜 / 制作**，可回到集列表。默认打开本集故事。
- **E3** 系列层与集列表并排提供 **世界**（设定 + 名册），不跟进某一集。
- **E4** 系列首页有可选的「整部戏一句话」。本集故事有「本集一句话」+ 剧本（可拖入 txt/md，写入剧本正文，不自动拆场）+ 场次卡片。
- **E5** 场次卡片字段：标题、发生什么、出场角色（从本戏世界名册多选）、地点（从本戏场景选）、时段。故事加一场 = 分镜里一个空场；镜头仍可没有场。
- **E6** 镜头挂在所属集上，不整部戏共用一张表。
- **E7** 分镜固定列：顺序、镜号、首帧、尾帧、成片。默认打开：时长、内容、角色、场景、备注。类别、声音、情绪、摄像机角度、装备、镜头焦段、场景特写可在列设置里打开，默认关。参考不占独立列，进首帧 / 尾帧 / 成片各自的生成槽。
- **E8** 已有本地项目和旧 zip：自动变成第 1 集；旧「画面」→ 首帧；旧「参考」图并进首帧槽的参考，不丢媒体。
- **E9** 制作页本任务仍为占位，只跟当前集走。不接真实 AI 出图/出视频。

## Out of scope

- 季作为一等对象（需要时仍只是集上的编号，本任务不做季 UI）
- 世界名册引用工作室库
- Notion 式任意插块编辑器
- 上传剧本后自动拆成场次
- 制作页真实功能、拍摄计划
- 协作、云同步、生成调用

## Acceptance Criteria

- [ ] AC1 新建项目后进入集列表，已有第 1 集；再新建得到第 2 集（E1）
- [ ] AC2 点第 2 集进入本集故事，顶栏是故事 / 分镜 / 制作；返回回到集列表。世界从系列层进入，两集看到同一份设定和名册（E2, E3）
- [ ] AC3 系列首页能写整部戏一句话；本集能写本集一句话和剧本，拖入 `.txt` / `.md` 后剧本正文更新（E4）
- [ ] AC4 加一场后能选角色和场景、填时段；分镜页出现对应场；删场后镜头还在、变成未分场（E5）
- [ ] AC5 第 1 集的镜头不出现在第 2 集的分镜表（E6）
- [ ] AC6 分镜表头为顺序 / 镜号 / 首帧 / 尾帧 / 成片；默认能改时长、内容、角色、场景、备注；列设置能打开摄像机类列（E7）
- [ ] AC7 旧项目打开后故事和镜头都在第 1 集；旧画面出现在首帧（E8）
- [ ] AC8 界面没有生成按钮或模型请求（E9）

## Key decisions

| Decision | Choice |
| --- | --- |
| 进项目第一屏 | 集列表，短片也显示第 1 集 |
| 世界 | 系列层，和集列表并排 |
| 集内流程 | 故事 / 分镜 / 制作 |
| 分镜列 | 首帧 / 尾帧 / 成片替换画面+参考 |
| 故事输入 | 结构化场次卡片 + 剧本可拖入文件 |
