# Web research retrospective

## Contracts learned during implementation
- A CORS preflight success does not certify authenticated transport or gateway errors. Credential-free native browser testing found readable usage authentication errors but opaque search/extract errors. Keep failures truthful and test authentication without a paid fallback.
- Raw character limits do not bound JSON tool results: control characters expand during serialization. Bound final serialized size before ledger publication so successful remote work can be persisted safely.
- Provider URLs must be validated at original length. Truncating them invents a different destination. Approval preview may shorten display while durable arguments retain the validated URL.
- A global search credential is not a model connector or project data. Keep it in its own local table, exposing only configured/enabled/revision to UI and tools.
- Existing task observation provenance can cite web tools; successful reading does not establish a creative business result.
