# 产品决定与本轮边界

用户决定：IP 是长期创作身份；项目可以关联 IP，也允许独立存在。项目类型为视频、图片、文案、播客、音乐。类型创建后不可更改，无跨类型复制。聊天仍为首页；未来聊天创建项目采用确认卡片。用户最后明确要求当前先占位、逐步完善功能。

本轮交付：全局导航、我的 IP 占位页、素材库汇总入口、设置与帮助入口、五类项目筛选及创建入口。视频仍调用现有真实流程；其余类型明确待开放且无写入。旧资产 URL 和视频数据保持可用。

后续再做：IP 档案持久化、项目/IP 绑定与筛选、助手读取 IP 背景、聊天创建确认卡片及相应提醒、新类型编辑器。没有把这些未来能力描述为已实现。

## 后续已确认：多 IP 与衍生创作

- 用户讨论单 IP 后，最终同意保留多个 IP 的组织方式。IP 是长期主体，不是第六种项目类型；项目仍允许独立存在。
- IP 标准形象、三视图、表情包、海报及周边图案先在图片项目中制作，采用不同创作方向/模板，共用图片工作区。
- IP 页面可提供“设计形象 / 制作表情包 / 设计周边”快捷入口，带入当前 IP 和创作方向；不新增全局“周边”一级菜单。
- 用户明确选定后，候选作品才能“设为 IP 标准形象”或“加入 IP 素材”；生成结果不自动成为正式设定。
- 商品规格、材质、打样、生产交付与订单管理属于后续独立需求，尚未进入本轮实现。
- 上述为后续产品设计决定，当前代码仍为占位实现。

## 已确认：素材库一级视图

- 素材库分成两个一级视图：**媒体与资料**、**创作设定**。
- 媒体与资料按内容类型浏览：图片、视频、音频、文档；内容可以被多个项目使用。
- 创作设定承载结构化、可复用的创作内容：角色、场景、道具、风格，以及后续的声音设定等。
- 这是信息架构决定，不代表当前已经实现统一媒体库、IP归属、版本或引用维护；这些能力仍需后续设计和实现。

## 已确认：素材归属与引用规则

### 三种主要归属

- **通用素材**：不属于任何 IP，可被所有项目使用，例如通用纹理、环境声、转场、公开参考资料。
- **IP 素材**：属于某个 IP，长期由该 IP 维护，例如标准形象、表情包规范、声音参考、片头音乐和视觉模板。
- **项目素材**：只服务于一次具体创作，例如本期录音、临时参考、候选结果和拍摄原片。

### 维护规则

1. 每项素材只有一个主要归属范围；“使用于哪些项目”单独记录为引用关系，不改变素材归属。
2. 新上传或生成的内容默认进入当前项目；用户明确执行“加入 IP 素材”或“加入通用素材”后才提升范围。
3. 从项目提升到 IP 或通用范围时创建独立快照，并保留来源项目和来源素材链接；后续修改不会反向覆盖原项目，也不会悄悄改变其他项目。
4. IP 或通用素材被项目使用时，项目记录所采用的素材版本。素材更新产生新版本，新项目默认使用最新版，旧项目保持原版本，用户可以主动更新引用。
5. 项目素材不出现在素材库默认视图中，但可以在项目内查看；项目归档时一并归档。IP 和通用素材继续保留。
6. 被引用的素材先归档，不直接硬删除；详情显示引用项目和使用位置。只有没有引用关系时才允许彻底删除。
7. 复制、提升、归档和删除都保留来源与操作记录，避免“同名素材”无法判断来源。

### UI 方向

素材库默认显示两个视图：媒体与资料 / 创作设定。两个视图都提供“归属”筛选：全部、通用、某个 IP、某个项目；详情面板显示来源、版本和引用位置。项目内素材选择器默认展示通用 + 当前 IP，项目临时素材单独列出。

用户已明确同意以上规则，并要求建立 IP 与素材库落地任务开始实现。
