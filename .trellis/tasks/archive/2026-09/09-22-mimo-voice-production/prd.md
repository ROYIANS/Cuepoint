# MiMo voice production

User requests a MiMo connector and integrated preset speech, voice design and voice cloning in the existing audio workspace. Preserve compact manuscript UX and existing shadcn controls.

## Acceptance
- Configure MiMo credentials with default https://api.xiaomimimo.com/v1, retain custom proxy base URLs, no secrets in jobs/Agent/ZIP.
- Generate preset, designed and cloned speech through existing durable jobs, versions and timeline adoption. Existing APIMart/music stays compatible.
- Named project speakers can save and reuse voice configuration; selected generated/imported audio can become a clone reference. Upload WAV/MP3 references and preserve across reload/ZIP.
- Design supports optional explicit text optimization and preserves returned final text separately from manuscript.
- Agent discovers MiMo and submits reviewed requests with scope/reference/connector checks and no automatic POST replay.
- Errors are visible, references must belong to project, clone sample format/encoded 10 MB bound validated before paid submission.
- Deterministic provider, runtime, repository, package and Agent regression tests pass. No live paid test required.
