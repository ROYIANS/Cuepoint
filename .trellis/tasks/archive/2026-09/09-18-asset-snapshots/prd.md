# 项目世界与工作室资产快照

## Goal

让工作室母版可复用到项目，同时保证项目资产可独立修改和完整备份。

## Requirements

- **A1** 项目世界可从工作室选择角色、场景、道具、风格并复制为快照。
- **A2** 快照拥有新 ID 和项目 owner；之后修改母版或快照互不影响。
- **A3** 快照复制所有字段、未知 `extra` 和槽位媒体；媒体记录归属项目。
- **A4** 项目世界完成道具与风格 CRUD/详情，不再使用占位。
- **A5** 项目 ZIP 往返保留四类资产、媒体、来源信息和未知字段。
- **A6** 删除母版不影响既有项目快照。

## Out of Scope

- 实时同步、手动从母版更新
- 工作室整库备份

## Acceptance Criteria

- [ ] AC1 四类工作室资产均可加入项目世界（A1）
- [ ] AC2 母版和项目快照互改不影响，删除母版后快照仍在（A2, A6）
- [ ] AC3 带图片/视频的快照在项目中正常显示且媒体 owner 正确（A3）
- [ ] AC4 项目道具和风格可新建、编辑、删除（A4）
- [ ] AC5 导出再导入后四类资产及媒体完整（A5）
