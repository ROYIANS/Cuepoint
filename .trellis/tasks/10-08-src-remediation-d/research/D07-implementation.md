## 2. Concrete owners and signatures

`baseUrl.ts` contains only the unchanged `baseUrl.trim().replace(/\/+$/, "")` normalizer. APIMart, audio, AIHubMix providerRoot, MiMo, Chat and Responses import that leaf directly. `openaiCompatible.ts` imports and re-exports it for actual `db/connectors.ts`, `audioGeneration/runtime.ts` and existing tests. Provider guards/route construction stay local.

`requestBoundary.ts` exports `requestOnce(url: string, init: Omit<RequestInit, "signal" | "credentials" | "redirect">, options: RequestBoundaryOptions): Promise<Response>`. The options require explicit `credentials` and `redirect`, with optional injected `fetchImpl` and caller `signal`. It performs a pre-fetch `throwIfAborted` and invokes the selected fetch once, forwarding prepared wire fields. It does not consume a body, transform transport exceptions, authenticate, create timers, call callbacks, retry or select an endpoint.

`readHttpJson(response, {success, failure}, signal?): Promise<unknown>` requires both policies. `native-json` calls the original `.json()`; `bounded-json` requires `maxBytes` and `fatalUtf8` and delegates to actual `boundedResponse.readResponseJson`. Successful read/parse failures throw their original objects. Unreadable non-2xx diagnostics alone return undefined, after shared `isReadAbort` excludes original AbortError/caller cancellation. Response status and provider validation stay with the adapter. Native mode retains its original lack of finite byte bounds; no Infinity budget or replacement bounded reader is introduced.

No copied reader/SSE/redaction/limit algorithm, provider factory, generic generation service, universal failure type, retry framework or new constants. The two new leaves have zero restored-static diagnostics and downward imports only.
