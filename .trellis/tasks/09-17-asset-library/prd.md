# 角色与场景资产库

## Goal

在已有项目工作区里管理完整角色、场景资产（多图槽 + 说明字段），图片存 IndexedDB，并进入同一套导入导出包。

## Background

依赖 `09-17-app-foundation`。分镜表稍后挂 `characterIds` / `sceneId`，本任务只提供资产 CRUD 与详情页。

## Requirements

- **A1** `/p/$projectId/assets` 分栏：角色 | 场景。可新建。
- **A2** 角色字段：名称、简介、外观说明、备注；图槽 正面/侧面/背面/表情/服装。本地选图，可替换、可清除。
- **A3** 场景字段：名称、地点、时段、氛围、备注；图槽 全景/中景/细节。同样本地选图。
- **A4** 可删除资产（确认）。删除后导出包不再包含该资产及其独占图片。
- **A5** 视觉跟工作区同一套留白/顶栏语言：列表卡片 + 详情编辑，不是另一套设计系统。
- **A6** 导出/导入包含资产与图片。

## Out of scope

- AI 生成图
- 在分镜单元格内编辑资产
- 服装/表情作为独立子实体（槽位即可）

## Acceptance Criteria

- [ ] 能新建角色并填齐字段、上传至少一张槽位图，刷新后仍在
- [ ] 能新建场景并上传槽位图，刷新后仍在
- [ ] 删除角色/场景后列表消失，导出 zip 不含该条
- [ ] 导入带资产图的 zip 能在详情页看到图
- [ ] 无项目或错误 id 时回到安全页
