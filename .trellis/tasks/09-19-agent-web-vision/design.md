# Integration design

Two sequential children share the Agent tools/skills and existing execution UI. Web research adds independent Tavily configuration and bounded network tools. Image discovery adds read-only named-project resolution and ledger-proven native pixel input. Child design.md files own exact contracts. Neither grants new business write permissions. Ordinary conversation mode remains tool-free; smart mode combines both skills.

Acceptance fixture: in a projectless smart conversation ask for public visual-reference research and comparison with a named project's existing shot image. Verify real tool result URLs, extraction coverage, discovered image labels and exact pixels, unchanged conversation binding and no search payload containing project images/documents. Repeat scoped rejection in a bound project and preserve source identity in task observations. Final child completes only after independent/native review and authorized commit/archive.
