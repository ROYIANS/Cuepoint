# 单片与连载项目模式

## Goal

让单片用户直接进入故事，同时保留连载用户的显式分集工作流。

## Requirements

- **M1** 项目模式为 `film | series`，新建默认 `film`。
- **M2** 单片仍有一个内部 Episode，但项目入口直接进入该集故事，顶栏不展示集管理。
- **M3** 连载保持当前集列表、系列一句话和分集导航。
- **M4** 旧项目和无 mode 的旧 ZIP 默认解释为 `series`。
- **M5** 新建对话框允许选择类型；项目模式写入 ZIP 并正确恢复。

## Out of Scope

- 单片和连载的任意互转
- 季模型

## Acceptance Criteria

- [ ] AC1 默认新建单片并直接进入故事（M1, M2）
- [ ] AC2 选择连载后进入集列表并能新增第 2 集（M3, M5）
- [ ] AC3 旧项目打开仍显示集列表（M4）
- [ ] AC4 单片/连载导出再导入后模式不变（M5）
- [ ] AC5 单片世界、分镜、制作仍使用其唯一 Episode（M2）
