# IP 与素材库落地报告

## 已实现

- 多 IP 档案：名称、定位、受众、主题、表达、视觉与声音偏好；创建、编辑、搜索、归档恢复；详情展示关联项目与专属素材。
- 项目归属：创建视频项目时可选 IP；旧项目可关联、变更或解除；项目列表可筛选 IP/独立/归档，工作区提供项目素材入口。
- 素材两视图：媒体与资料（图片、视频、音频、文档）及创作设定（角色、场景、道具、风格）。复用现有编辑库，支持版本化快照和旧素材提升。
- 单一归属：全局、IP、项目；默认共享视图排除项目素材。归属与视图保存在 URL，刷新和切换视图不会改变明确筛选。
- 维护：名称、备注、标签、搜索、类型/归属/状态筛选、预览与原文件下载；导入媒体与文档；PDF/DOCX 按需提取文字预览。
- 不可变版本：上传新版本、从原设定保存快照、查看历史、保存独立副本、加入项目并固定版本、显式加入新版副本。现有镜头与编辑内容不被自动替换。
- 归档恢复与引用保护：使用中素材无法永久删除；未使用副本可移除，发现封面/镜头/设定/任务历史仍引用则整笔回滚；共享快照不依赖来源项目生命周期。
- UI 采用现有 Select、Tabs、Button、Input、Textarea、Checkbox、Dialog、Sheet、AlertDialog；没有新增可见原生选择框。文件选择由已有按钮触发隐藏输入，音视频沿用现有媒体预览的播放控件方式。
