# 全站 UI 审查与风格统一

验收状态：全站产品实施、原生复核与最终质量门已完成。用户于 2026-10-10 确认“按方案提交并归档”；工作提交、归档和 journal 按顺序执行，最终生命周期与 commit 见 task.json 和开发者 journal。

## 目标与价值

将断续开发形成的多套风格统一为克制的深色创作工作台，为后续跨平台桌面版准备稳定的导航、页面层级、操作区、窗口布局和键盘体验。用户点名“项目”和“素材库”，范围覆盖全站。

## 背景与证据

- 2026-10-10 用户同意创建任务；随后选择推荐的 A 方向，并明确“这次 UI 改造，可以都改”“去除 Web 的味道”，允许全站视觉与页面结构调整。
- [路由清单](research/route-inventory.json)覆盖 47 个路由文件：25 个页面适配、1 个持久 Agent 宿主、3 个视图选择、10 个 Provider/Shell/Outlet 布局、8 个重定向。路由文件数不是独立页面数。
- [Studio 审查](research/routes-and-studio-audit.md)与[工作区审查](research/workspaces-and-theme-audit.md)保留差异、位置、严重度与业务约束；源码风险不等于已复现的显示故障。
- [初始原生基线](research/native-baseline.md)实查 7 页；进入实施前补齐 31 个上下文的改前截图，实施后补齐桌面与窄窗截图及交互检查。项目原标题 serif 28px/400/28px，素材库 sans 30px/600/45px；现在采用统一功能页头。证据方法和适用限制见[覆盖矩阵](research/audit-coverage.md)。
- React 19、Vite、TanStack Router、Dexie；既有 shadcn/Radix，Agent 局部 LobeHub/antd。交互界面仅暗色、打印浅色。任务开始时 main 与 origin/main 一致，产品代码无未提交修改。

## 已确定的产品决定

采用深色中性色、白色主要动作、黑体 UI 标题和功能命名；减少宣传式大标题、装饰眉题和重复说明。可调整全站导航/框架，以紧凑页头、稳定工具栏、结构面板和明确滚动区统一全局/项目页面。保留现有控件圆角、边框、阴影、焦点；不加装饰左色条或多层圆角卡片。分镜表、时间线、连续文稿、聊天及打印保留明确功能例外，当前窄屏 Web 仍可用。桌面运行环境属于后续任务。

## 范围

Studio：项目、素材、IP 列表/详情、角色/场景/道具/风格列表/详情、连接与模型、关于及适用弹窗。项目：视频剧集、故事、世界/资产详情、分镜、制作/打印、记忆，音频/音乐及检查器、审核/排列弹窗。Agent：欢迎、会话、任务、话题/上下文/执行/生成审核。共享导航、页面/面板、控件/表单、状态、卡片操作、Dialog/Sheet、缩放/滚动全部纳入。

## 范围外

桌面框架/打包安装、OS 标题栏/窗口控件/拖动区、原生菜单/文件桥接、更新器/权限；新增浅色主题、字体资产包、云同步、schema/供应商改造、全局命令面板、多项目持久页签。保留既有快捷键，不为样式统一新增业务流程。

## 验收标准

- AC1 → R1：47 路由全部映射；项目种类与 Studio/项目详情上下文无遗漏。
- AC2 → R3/R4：项目/素材的标题层级、动作位置、工具栏几何、内容起点一致，页签/筛选语义正确。
- AC3 → R2/R3/R4：矩阵每个实际页面/上下文完成改前/改后原生检查，适用状态/弹窗有证据；功能例外有说明，未解释的样式偏差处理完毕。
- AC4 → R5：代表页面族在 1440×900、1280×720、1024×640、1280×600、390×844 的适用布局可操作；受影响断点两侧实查，无非预期整页横向溢出或不可达弹窗动作。
- AC5 → R4/R5：Tab/Shift+Tab、Enter/Space、Escape、菜单/弹窗焦点返回、已有快捷键正常；窗口变化与页面切换保留当前业务生命周期中的草稿、选中项、播放和运行。
- AC6 → R4/R6：类型检查、全量 Vitest、quality 全模式、自测、model-bank 验证和构建通过，高风险所有权/草稿/审批/时间线/Agent/打印契约无回归。
- AC7 → R6：更新规范、保留独立报告/原生证据，验收完成后提交和归档，不推送。

## 风险与技术备注

重点：Agent 持久宿主/局部主题/Portal/阅读滚动；编辑草稿/所有权；音频坐标/实际时长/批量审批；打印加载屏障。错误/缺失/dirty close 可在隔离本地项目或受控夹具验证，证据注明环境，不改用户现有项目或连接制造故障。样式验收无需付费供应商调用。

字体沿用本地中文 sans 回退链，功能 UI 不依赖远程装饰字体。字形随 OS 变化；Windows/Linux 真机和桌面窗口 API 验收在后续任务，本轮不宣称完成跨平台原生验收。
