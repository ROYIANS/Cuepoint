# AI 能力边界与组件

## 相对 ChatGPT Web（=100）的粗标定

| 能力 | 纯前端+BYOK 大约 | 备注 |
| --- | --- | --- |
| 开放域闲聊 | 25–40 | 缺工具生态与云端记忆 |
| **分镜域内**结构化智能 | 55–75 | 强 schema + 工作流时可超过裸聊 |
| 出图 | 50–70 | 取决于供应商 |
| 出视频 | 40–65 | 异步 task 模型合适 |
| 长期跨设备记忆 | 15–30 | 本机可以；跨设备要同步方案 |
| 关页后的多步 Agent | 30–45 | 需桌面/用户 Worker；单步异步生成除外 |

产品应对齐 **域内工作流分数**，不追通用助手 100。

## 异步生成（已确认方向）

许多出图/视频网关（如 **apimart**）模式为：

1. 提交任务 → `taskId`  
2. 客户端（或桌面后台）按 id 查询  
3. 成功后写入镜头槽位 / media  

`taskId` 与状态应落在本机任务/作业表，而不是你们服务器。

## 记忆 / Skills / MCP

| 组件 | 纯前端 | 说明 |
| --- | --- | --- |
| **记忆** | 可以 | 项目摘要、偏好、Canon/Lessons 存 Dexie |
| **Skills** | 可以 | 本地「说明书 + schema + 何时调用」 |
| **应用内 Tools** | 可以 | 读写作集、建任务、提交生成作业 |
| **真 MCP** | 基本不行 | 需桌面或用户自备 Gateway；Web MVP 不做 |

对外表述建议：**本机 Agent + Skills + 异步生成**；不承诺浏览器内完整 MCP 生态。
